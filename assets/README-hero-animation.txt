This folder is used to host the homepage Lottie animation locally.

Steps:
1. Download the .lottie file from your current Lottie URL:
   https://lottie.host/69b06f53-b4a3-41d4-b8d3-3640d3194555/cK7nrUMnF0.lottie

2. Save it into this folder with the exact name:
   hero-animation.lottie

3. When you prepare your deploy/ folder or zip for Cloudflare Pages,
   make sure the assets/ folder (with hero-animation.lottie inside it)
   is included so the animation can load from your own domain.
